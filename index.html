NOAA Weather Layers on One Map

A proof of concept that pulls GFS, HRRR, MRMS radar and GOES satellite data straight from NOAA Open Data on AWS, processes it to Cloud-Optimized GeoTIFFs and map overlays, and animates it in the browser.

What this shows

  • GFS temp – NOAA GFS 0.25° 2 m temperature, f000–f048 every 3 h
  • HRRR radar fcst – NOAA HRRR composite reflectivity, f00–f12 every 2 h
  • MRMS radar – observed MRMS merged composite reflectivity, latest 6 scans ~10 min apart
  • GOES IR – GOES-19 ABI band 13 (10.3 µm) brightness temperature, CONUS sector, latest 6 scans ~10 min apart
  • All data from NOAA Open Data Dissemination on AWS, fetched anonymously over HTTPS
  • Extent: CONUS incl. Florida. Static snapshot: updates only when the pipeline is rerun
Data: NOAA/NCEP Global Forecast System (GFS); NOAA/NCEP High-Resolution Rapid Refresh (HRRR); NOAA NSSL/NCEP Multi-Radar/Multi-Sensor System (MRMS); NOAA GOES-R Series/NESDIS (GOES-19 ABI) — all via the NOAA Open Data Dissemination (NODD) program on AWS. Built with: MapLibre GL JS, xarray, cfgrib/ecCodes, rasterio (GDAL/PROJ), h5netcdf, NumPy, Pillow. Basemap: OpenFreeMap © OpenMapTiles © OpenStreetMap contributors.
