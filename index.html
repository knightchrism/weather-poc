GFS 2 m Temperature Forecast Map

A proof of concept that pulls NOAA GFS forecast data straight from NOAA Open Data on AWS, processes it to Cloud-Optimized GeoTIFFs and map overlays, and animates it in the browser.

What this shows

  • Model: NOAA GFS 0.25°, 2 m air temperature
  • Forecast hours f000–f048, every 3 h, from the latest available run
  • Source: NOAA Open Data Dissemination on AWS (noaa-gfs-bdp-pds), fetched via HTTP byte-range for just the needed GRIB2 message
  • Extent: CONUS incl. Florida
  • Static snapshot: data updates only when the pipeline is rerun
Data: NOAA/NCEP Global Forecast System (GFS) via the NOAA Open Data Dissemination (NODD) program on AWS. Built with: MapLibre GL JS, xarray, cfgrib/ecCodes, rasterio (GDAL), NumPy, Pillow. Basemap: OpenFreeMap © OpenMapTiles © OpenStreetMap contributors.
